# CropLens AI - Test Plan & Verification Matrix

## 1. Automated Test Execution
Automated logic and schema unit tests are written with `node:test` and executed via `npm test` (`tsx --test src/utils/validation.test.ts`).

## 2. Test Verification Matrix

Standard status legend:
- **PASSED**: Verified and passing in automated tests, compilation, or live environment.
- **NOT_RUN**: Defined in test suite or manual test procedures; scheduled for formal field trial or end-to-end integration run.
- **BLOCKED**: Requires external cloud provision or external third-party hardware.
- **FAILED**: Executed and failed (none currently).
